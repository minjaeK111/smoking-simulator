# 흡연 시뮬레이터

금연 홍보용 인터랙티브 웹페이지. 세 사람(1일·1개월·10년 흡연)을 고르고 첫 담배를 피운 나이를 정하면, 피운 담배 수·쓴 돈·들이마신 타르·줄어든 수명과 오늘 끊었을 때 되찾는 수명을 계산해 보여 줍니다.

- 3D 담배 스테이지, 호흡하는 3D 폐, 70세까지 피울 담배 더미 (Three.js r128, CDN)
- 수치 근거는 페이지 하단 「계산 기준과 출처」 참고

## 열기

`index.html`을 브라우저로 열면 됩니다. 폰트와 Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 연결이 없으면 3D 없이 내용만 표시됩니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 바로 열 수 있는 완성본 |
| `src.html` | 원본 (doctype/head 래퍼가 없는 형태). 수정은 여기서 |
| `build.sh` | `src.html` → `index.html` 생성 |

수정 후:

```bash
sh build.sh
```

인물 사연은 `src.html`의 `CHARS`, 담배 가격·타르·개비당 수명 단축은 `PRICE_PER_CIG`, `TAR_MG`, `MIN_PER_CIG`에 있습니다.
